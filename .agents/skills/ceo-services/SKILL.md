# CEO services

In a source checkout, read `docs/contract/services.md` at the repository root before acting at this trigger.
In an installed home, run `ceo help contract services` to retrieve this build's complete procedure from the same policy source.
The installed file is also at `docs/contract/services.md` under `CEO_HOME`.
A legacy tracked-checkout home keeps its own contract; do not infer activation from a newer binary or shared skill alone.
Follow only the steps applicable to the current role and authorized task.
For exact command syntax, use `ceo help <command>` or a listed subcommand topic.
Run `ceo help` to list available topics without loading their bodies.
If a required reference is missing or help fails, report the failure and stop the dependent action; do not infer the missing rules.
