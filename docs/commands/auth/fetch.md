# cfo auth fetch

`cfo auth fetch <request> --task <id>`

Have the supervisor read the keys an open credential request still needs from the request's link, when a reviewed recipe in `config/key-pages.json` reads that page, and store them as the request's card does.
It prints the names stored and nothing of the page.
A signed-out page puts his sign-in card in the Command Center, and the fetch carries on by itself once he has signed in.
Any harness's goblin may run it for its own request ([Browser key fetching](../../native-board.md#browser-key-fetching))
