# cfo process-plan

`cfo process-plan`

Say what the fleet's process sweeps would end on this machine now, and end nothing.
It reads the machine's processes and this home's terminals, task records and monitor records, and writes nothing into the home.
It lists what the janitor's hourly sweep would end now, what a sweep an hour on would end if each goblin that rests stayed at rest and nothing it watches did anything, what it would name for you, and what it would leave, each with the rule that decides it, then what a cleanup or a relaunch of each task would end beside the task's terminal.
Every would-end process is checked a second way, apart from the rule that would end it, and one that looks like the Overlord's (a desktop program or what one started), the CFO terminal's, a working goblin's or another terminal's is listed first, under Alarms.
The sweep acts on the same plan this prints.
Run it before installing a build that changes what the sweeps end
