# cfo remote

`cfo remote on\|status\|off`

Optional private phone access to the board and existing CFO terminal through Tailscale Serve HTTPS, restricted to the PC owner's discovered Tailscale account.
Off by default.
On verifies the exact route and enables existing Start at login; status diagnoses it, and while access is off names what this PC's Tailscale lacks and the command that mends it; off revokes and disconnects remote views without ending terminals or local views.
The CFO Task panel's Remote access setting has the same controls and a copyable link, and on the PC each mending command with a play button that runs it in a PowerShell terminal drawn in the section, never a Command Center item, whose end the CFO is not told of; on the private board, where another machine of the owner's on the tailnet answers with its board, a picker opens that machine's private board; and in the phone's Home Screen app an App badge switch subscribes the app to the supervisor's pushes of each new Command Center item and the count, which raise its icon's count while it is closed and which it corrects as it opens; turning remote access off forgets every app.
`on` and `off` are refused in a goblin's or a gate agent's terminal.
Never enable Funnel, reset unrelated Serve routes, or relax PC-only actions.
