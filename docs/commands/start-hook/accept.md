# cfo start-hook accept

`cfo start-hook accept <task-id> <file> [--fleet]`

Accept a [start hook](../../contract/worktrees.md#code-that-runs-at-every-python-start) a goblin's seal stopped, once you judged it safe: the file, a path in the task's worktree as its wake names it, by its name, its exact content and the distribution whose `RECORD` installs it, for the goblins of the task's project, or of every project with `--fleet`.
Their seals let it through at every install from then on and still stop it once any of the three differs.
It refuses a file no installed distribution names and a folder, and is yours alone: a goblin's or a gate agent's terminal is refused it
