# cfo question

`cfo question --id <stable-id> --text "<user question>" [--option "<choice>"]... [--recommend "<exact-choice>"]`

registered CEO opens a user decision modal with Other; the answer returns as one normal native message, not a native prompt-tool response

`--text` leads with the plain decision, the recommendation and what each choice does, and puts run IDs, findings and other evidence after a line that reads only `Details:`, which his card folds under Technical details.
Read the [applicable decisions procedure](../contract/decisions.md) before acting.
