# cfo deliver

`cfo deliver --id <stable-id> --title "<what it is>" --file <path> [--download] [--task <id>]`

hand the Overlord a file as a Scrawl page that shows it, presented in the Command Center; what he writes there reaches you as a review wake, and --download offers it to download, for a generated asset or a file he asked to keep

Read the [applicable decisions procedure](../contract/decisions.md) before acting.
